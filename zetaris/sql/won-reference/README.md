# Weather-or-Not reference SQL (not run by Crosswalk)

These files are the sister entry's verified Lightning SQL pairs (`NN_won_*_create.sql` / `_select.sql`), its `manifest-won.json` and its `README-won.md`, copied unchanged from Weather-or-Not (same author, Apache-2.0) as a reference for Crosswalk's Zetaris lane: the REST and FILESTORE table shapes, the `LATERAL VIEW explode(...)` views, the station-filtered GHCN views, the USL with PK/FK and the DQ rule, with the counts and timings that were measured there.

They name Weather-or-Not's objects (`WON_SEC`, `WON_DNS`, `WON_GHCN`, container `won`, namespace `lightning.metastore.weatherornot`, USL `weather_or_not_usl`). Crosswalk's own objects are `CW_SEC`, `CW_DNS`, `CW_GHCN`, `CW_FEMA`, container `cw`, namespace `lightning.metastore.crosswalk`, USL `crosswalk_usl`; they live in `zetaris/sql/` above this folder and in `zetaris/manifest.json`. Nothing in this folder is declared in the manifest, run by `gateway/run_sql.py` in a Crosswalk session, or allowed by the Crosswalk gateway allowlist (which refuses `WON_*` and `won.*` names). Both projects share one Zetaris instance: Weather-or-Not's objects are never dropped, altered, cached or uncached from here.
